Flagship project

TriadMusic — music
meets engineering.

A full-stack platform for worship musicians, built solo from architecture to deployment. With a growing AI layer.

TriadMusic manages band scheduling, song libraries, playlists, and live audio tools for worship teams. Built entirely solo since 2022 — Go API, Nuxt 3 frontend, mobile apps, and a complete AI integration layer using pgvector, LM Studio, and Deepseek R1.

Recently migrated search from Algolia to a custom PostgreSQL hybrid vector search using Nomic AI embeddings, achieving the same quality at zero marginal cost.

AI integration deep dive

AI-powered
Hybrid Semantic Search (pgvector)

Migrated from Algolia to custom PostgreSQL hybrid search. Songs, lyrics, and chords vectorized with Nomic AI embeddings — full semantic similarity search at zero marginal cost.

RAG Pipeline + LM Studio

Full Retrieval-Augmented Generation pipeline in TypeScript. LM Studio SDK with JSON-backed vector store, supporting Deepseek R1 chat with real-time song database context injection.

Custom Embedding Models

Evaluated and deployed nomic-embed-text and text-embedding-nomic-ai400 via LM Studio SDK, tuned for music metadata and lyrical content retrieval.

Audio-to-MIDI (two iterations)

ML-based audio analysis converting live or recorded audio to MIDI. Musicians transcribe played notes and chords directly in the platform.

Chord Detection Engine + AI Playlist Generation

Custom chord detection microservice using audio DSP for real-time chord identification from audio input. In progress: LLM-powered playlist generation from natural language prompts respecting key, mood, and usage history.
